# Paleta de Colores

Aplicación web para generar paletas de colores aleatorias en formato HEX y HSL.

## Instrucciones de Uso
1. Selecciona el tamaño de la paleta (6, 8 o 9 colores).
2. Selecciona el formato de color (HEX o HSL).
3. Haz clic en "Generar Paleta" para crear colores aleatorios.
4. Usa el botón "Copiar" para copiar el código del color.

## Estructura del Proyecto
- `index.html` - Estructura HTML con header, selectores y grid de colores
- `script.js` - Lógica JavaScript para generar colores aleatorios (HEX y HSL)
- `css/` - Estilos organizados en módulos:
  - `base/` - Estilos base
  - `components/` - Componentes reutilizables
  - `layout/` - Layout de la página
  - `responsive/` - Media queries

## Características
- Generación aleatoria de colores en HEX y HSL
- Selección de tamaño de paleta (6, 8 o 9 colores)
- Copia al portapapeles con un clic
- Feedback visual con fantasma animado
- Diseño responsivo

## Tecnologías
- HTML5 semántico
- JavaScript vanilla
- CSS modular y responsivo
